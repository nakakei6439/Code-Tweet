## 1. プロダクト概要

GitHub リポジトリの README やプロジェクト説明から、X（旧 Twitter）向けのマーケティングポストを Gemini API で **5 件まとめて自動生成**する個人開発者向け Web アプリ。

各ポストは以下の **5 段ストーリーアーク**で生成される：

1. **紹介**：プロダクトを一言で
2. **使い方**：誰がどう使うか
3. **ユースケース**：実例
4. **共感**：解決する痛み
5. **CTA**：URL リード文付きの行動喚起

各ポストには **推奨投稿日時**（翌日〜7 日以内）と **選定理由**が AI によって添えられる。

本番 URL: https://code-tweet.vercel.app/

## 2. ターゲットユーザー

### 主ターゲット（A）
**毎週コンスタントに X でポストする個人開発者**

- ペルソナ例：個人で SaaS を 1〜2 個運営している副業エンジニア（30 代男性）
- 週 5〜10 回ポストしたいが、毎回ネタを考えるのが大変
- 月 1,000 円以内なら継続のための仕組みに払う
- 日本語で発信している

### 副ターゲット
- これから X 運用を始めたい開発者（無料枠で価値検証）
- 複数プロダクト運営の専業個人開発者（Pro 上限が刺さる）

## 5. 非機能要件

### 5.1 パフォーマンス
- ポスト生成：Gemini Flash 使用で 5〜15 秒以内（5 件まとめ生成）
- README 取得：3 秒以内
- 残り回数表示：初期 SSR で即時表示（フリッカーなし）

### 5.2 セキュリティ
- **API キーはサーバー専用**：`GEMINI_API_KEY` / `SUPABASE_SERVICE_ROLE_KEY` / `GITHUB_PAT_ENCRYPTION_KEY` は `NEXT_PUBLIC_` を付けず、クライアントに渡さない
- **ユーザー PAT・OAuth トークンは AES-256-GCM 暗号化**：DB に平文で保存しない
- **RLS（Row Level Security）**：`subscriptions` / `usage_logs` / `user_tokens` は user_id ベースのポリシーで保護
- **Service Role Key の使用は API ルート内のみ**：admin client はサーバー側のみで使用
- **IP ハッシュ化**：ゲスト識別は SHA-256 でハッシュ化した IP を保存（生 IP は保存しない）

### 5.3 可用性
- ホスティング：Vercel（Fluid Compute）
- DB：Supabase（マネージド PostgreSQL）
- Gemini 過負荷時：503 エラーで「混雑中」メッセージ。リトライはユーザー手動

### 5.4 拡張性
- 新しい AI プロバイダ追加：`src/lib/gemini.ts` の I/F に合わせて差し替え可能（V5 で Claude 追加予定）
- 新しい SNS 対応：プロンプト差し替えで対応（V9 で Instagram 等）

## 6. 主要ユーザーストーリー

### US-01：個人開発者がアップデート告知のポストを作る（無料ユーザー）

> 田中さんは個人で開発した SaaS の機能アップデートを X で告知したい。/ にアクセスし、GitHub でログイン。「今月あと 8/10 回」と表示されるのを確認。GitHub URL を貼って README を取得 → トーンに「フランクに」と入れて生成。5 件のポストと推奨日時が出る。ワンクリックでコピーして X に投稿。

### US-02：Pro ユーザーが自分のリポジトリ一覧から選ぶ（V8 Phase A.5 後）

> 田中さんは Pro にアップグレード済み。設定ページから「GitHub と連携」ボタンを押す → OAuth 認証で連携完了。/ に戻り「自分のリポジトリから選ぶ」ボタンを押すと、自分の公開・非公開リポジトリ一覧がモーダルで表示。「team-mvp（private）」を選ぶと URL が自動補完されて README 取得 → 生成。

### US-03：無料ユーザーが上限到達 → Pro へアップグレード検討（V8 Phase A.5 後）

> 田中さんが無料プランで 10 回使い切った。エラーボックスに「Pro プラン（月 980 円）で月 100 回まで拡張されます」と表示され、「Pro プランへ」ボタンが出る。クリックすると `/pricing`（Phase B 実装予定）へ遷移。

### US-04：ゲストが上限到達 → ログインへ誘導

> 初訪問者がアプリを試して 3 回生成したところで上限到達。エラーに「GitHub ログインで月 10 回まで拡張されます」と「GitHub でログイン」ボタンが表示される。

## 7. 制約・前提条件

- 対応言語：日本語のみ（プロンプトが日本語前提）
- 対応 SNS：X（旧 Twitter）のみ。文字数判定は `twitter-text` の weighted length
- 対応リポジトリ：GitHub のみ（GitLab・Bitbucket は対象外）
- 対応 AI：Gemini 2.5 Flash（V5 で Claude 追加予定）
- 既存ユーザー：実質 0 名（中川さん本人のみ）→ 仕様変更時の影響ゼロ
