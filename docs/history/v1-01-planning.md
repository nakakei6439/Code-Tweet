# STEP 1: 企画メモ - Code Tweet（仮称）

---

## アプリの概要

**プロジェクトのテキスト（README等）またはGitHubリポジトリを読み込んで、マーケティング用ポストを1週間分AIで自動生成し、投稿を管理できる個人開発者向けWebアプリ。**

---

## 誰のため？

- 自分のプロダクトをTwitter/X でSNS宣伝したい個人開発者・エンジニア
- 毎日ポストのネタを考えるのが大変な人
- 最終的には多くの人に使ってもらうことを目指す

---

## まず作る機能（V1）

外部サービスを最小限にして、デバッグしやすい状態からスタートする。

| # | 機能 | 内容 |
|---|------|------|
| 1 | テキスト貼り付け | README などをコピペで入力する欄 |
| 2 | 口調メモ欄 | 「フランクな感じで」などAIへの注文を自由記述 |
| 3 | ポスト生成 | Gemini APIで7件のポストを自動生成 |
| 4 | コピーボタン | 1件ずつクリックでコピーできる |

**使う外部サービス：Gemini API のみ（1つだけ）**

---

## 後から追加する機能

| 順番 | 機能 | 追加する外部サービス |
|------|------|-------------------|
| V2 | GitHub URL から README を自動取得（公開リポジトリ）+ ログイン + 利用制限 | GitHub API / Supabase Auth |
| V3 | GitHub プライベートリポジトリ対応 | GitHub API（トークン連携） |
| V5 | Claude API も選択可能に | Claude API |
| V8 | フリーミアム導入（現行: ゲスト 3 回まで / 無料 月3 / Pro 月30。Stripe は Phase B 予定） | Supabase / Stripe |
| V9 | Instagram・Threads など他 SNS 対応（保留） | なし |

---

> この企画メモは V1 開始時点の記録です。現在は Google ログインではなく GitHub OAuth を採用し、生成数も 7 件ではなく 5 件に変更しています。最新仕様は [`../product/requirements.md`](../product/requirements.md) を参照してください。

## 基本的な使い方の流れ（V1）

```
① アプリを開く
    ↓
② READMEなどのテキストを貼り付ける
    ↓
③ 口調メモを書く（例：「フランクな感じで」）※任意
    ↓
④ Gemini APIキーを入力する
    ↓
⑤「生成する」ボタンを押す
    ↓
⑥ 7件のポスト案が表示される
    ↓
⑦ コピーしてTwitterに手動投稿する
```

## 競合調査まとめ

### 主な競合サービス
- **汎用AIポスト生成**：Hootsuite、Tweet Hunter、Typefully、Postwise など（月額$20〜$200）
- **GitHub連携ツール**：AiToEarn、Probot Twitter など（オープンソース・機能が限定的）

### このアプリの差別化ポイント
1. **GitHubリポジトリの内容から直接ポストを生成**（既存は手入力ベースがほとんど）
2. **個人開発者のプロダクト宣伝に特化**（企業向けではなくシンプルなUI）
3. **1週間分を一貫したストーリーで生成**（「紹介→使い方→活用例→技術的利点」の流れ）
4. **日本語対応・日本の個人開発者市場**（英語サービスが多く、日本語特化の競合が少ない）

## 収益化の方針

- **買い切り型は採用しない**
- まずユーザーを集めてから収益化する

| フェーズ | 内容 |
|---------|------|
| V1〜V3 | 完全無料で公開・ユーザーを集める |
| V7 | Google AdSense を追加（広告収入） |
| V8 | フリーミアム＋月額サブスク導入 |
| 将来 | 有料ユーザーは広告なし |
