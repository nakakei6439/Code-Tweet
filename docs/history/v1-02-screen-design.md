# STEP 2: V1 画面設計 — Code Tweet

## デザイン方針

**ダークテーマ** を採用。参照元: `Downloads/カラフルな入力フォーム 2/src/app/App.tsx`

| 要素 | 仕様 |
|------|------|
| 背景 | `bg-gray-950`（ほぼ黒） |
| 背景装飾 | 右上にシアン・左下にフューシャの blur 円 |
| フォームカード | `bg-gray-900/80 backdrop-blur-xl border border-gray-800` |
| ネオンライン | カード上部に `via-cyan-500` グラデーションライン |
| 生成ボタン | `from-cyan-500 via-fuchsia-500 to-yellow-500` グラデーション |
| フォーカス色 | プロジェクト説明=シアン／口調=フューシャ／APIキー=イエロー |

## UIステート

| ステート | 挙動 |
|---------|------|
| 初期状態 | フォームのみ表示。結果エリア非表示 |
| 入力中 | 通常。必須項目が空ならボタン disabled |
| 生成中 | ボタン → スピナー＋「生成中...」に変化。フォーム disabled |
| 生成完了 | TweetCard × 7 が結果エリアに表示。ページを結果位置へスクロール |
| コピー済 | コピーボタン → 「コピーしました ✓」に 2 秒間変化 |
| エラー | ボタン下に赤バナー表示。フォーム再有効化 |

## コンポーネント構成（Next.js App Router）

```
app/
  layout.tsx            ← <html lang="ja">、メタデータ、フォントセット
  page.tsx              ← 全体レイアウト・状態管理（useState）
  api/
    generate/
      route.ts          ← Gemini API 呼び出し（サーバーサイド Route Handler）

components/
  TweetCard.tsx         ← ポスト1件 + コピーボタン（コピー状態管理）
```

状態管理は `page.tsx` に集約。`TweetCard` のみコピー状態を持つため分離。
