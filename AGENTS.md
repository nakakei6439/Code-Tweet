## Browser verification

When opening this project in Google Chrome for local debugging, use the existing Chrome profile named `DEBUG`.

Chrome's internal profile directory for `DEBUG` is `Profile 8`. Use:

```bash
open -na "Google Chrome" --args --profile-directory="Profile 8" http://localhost:3000
```
