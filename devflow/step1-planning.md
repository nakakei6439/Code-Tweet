# STEP 1: 企画メモ - Code Tweet（仮称）

---

## アプリの概要

**プロジェクトのテキスト（README等）またはGitHubリポジトリを読み込んで、マーケティング用ツイートを1週間分AIで自動生成し、投稿を管理できる個人開発者向けWebアプリ。**

---

## 誰のため？

- 自分のプロダクトをTwitter/X でSNS宣伝したい個人開発者・エンジニア
- 毎日ツイートのネタを考えるのが大変な人
- 最終的には多くの人に使ってもらうことを目指す

---

## まず作る機能（V1）

外部サービスを最小限にして、デバッグしやすい状態からスタートする。

| # | 機能 | 内容 |
|---|------|------|
| 1 | テキスト貼り付け | README などをコピペで入力する欄 |
| 2 | 口調メモ欄 | 「フランクな感じで」などAIへの注文を自由記述 |
| 3 | ツイート生成 | Gemini APIで7件のツイートを自動生成 |
| 4 | コピーボタン | 1件ずつクリックでコピーできる |

**使う外部サービス：Gemini API のみ（1つだけ）**

---

## 後から追加する機能

| 順番 | 機能 | 追加する外部サービス |
|------|------|-------------------|
| V2 | GitHubのURLからコードを自動取得 | GitHub API |
| V3 | 生成したツイートを保存できる | Supabase DB |
| V4 | スケジュール管理（投稿日時を設定・一覧表示） | なし |
| V5 | Claude APIも選択可能に | Claude API |
| V6 | ログイン機能（Google認証） | Supabase Auth |
| V7 | 広告の実装（Google AdSense） | AdSense |
| V8 | フリーミアム導入（無料：月3回／有料：無制限） | Stripe など |
| V9 | Instagram・Threads など他SNS対応 | なし |

---

## 基本的な使い方の流れ（V1）

```
① アプリを開く
    ↓
② READMEなどのテキストを貼り付ける
    ↓
③ 口調メモを書く（例：「フランクな感じで」）※任意
    ↓
④ Gemini APIキーを入力する
    ↓
⑤「生成する」ボタンを押す
    ↓
⑥ 7件のツイート案が表示される
    ↓
⑦ コピーしてTwitterに手動投稿する
```

---

## 競合調査まとめ

### 主な競合サービス
- **汎用AIツイート生成**：Hootsuite、Tweet Hunter、Typefully、Postwise など（月額$20〜$200）
- **GitHub連携ツール**：AiToEarn、Probot Twitter など（オープンソース・機能が限定的）

### このアプリの差別化ポイント
1. **GitHubリポジトリの内容から直接ツイートを生成**（既存は手入力ベースがほとんど）
2. **個人開発者のプロダクト宣伝に特化**（企業向けではなくシンプルなUI）
3. **1週間分を一貫したストーリーで生成**（「紹介→使い方→活用例→技術的利点」の流れ）
4. **日本語対応・日本の個人開発者市場**（英語サービスが多く、日本語特化の競合が少ない）

---

## 収益化の方針

- **買い切り型は採用しない**
- まずユーザーを集めてから収益化する

| フェーズ | 内容 |
|---------|------|
| V1〜V3 | 完全無料で公開・ユーザーを集める |
| V7 | Google AdSense を追加（広告収入） |
| V8 | フリーミアム＋月額サブスク導入 |
| 将来 | 有料ユーザーは広告なし |
